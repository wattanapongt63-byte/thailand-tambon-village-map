แผนที่ตำบล + รายชื่อหมู่บ้าน

เลือกจังหวัด → อำเภอ → ตำบล แล้วดาวน์โหลดภาพแผนที่พร้อมรายชื่อหมู่บ้านทั้งหมด (ใช้เพื่อการศึกษา ไม่มีค่าใช้จ่าย)

ข้อมูลขอบเขตตำบลจากโครงการ prasertcbs/thailand_gis (แปลงจาก HDX COD-AB Thailand) ข้อมูลรายชื่อและพิกัดหมู่บ้านจาก กรมการปกครอง กระทรวงมหาดไทย (ปรับปรุงล่าสุด มิ.ย. 2568) ใช้เพื่อการศึกษาเท่านั้น ข้อมูลเขต/แขวงในกรุงเทพมหานครไม่มีรายชื่อหมู่บ้าน เนื่องจากกรุงเทพฯ ไม่ได้อยู่ในระบบ อำเภอ/ตำบล/หมู่บ้านแบบจังหวัดอื่น
