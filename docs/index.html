แผนที่ตำบล Learning T-Map

เครื่องมือสำหรับครูและบุคลากร สกร. ใช้ประกอบการจัดทำแผนที่แหล่งเรียนรู้ระดับตำบล

🗺️
ดูแผนที่ตำบลพร้อมหมู่บ้าน

เลือกจังหวัด → อำเภอ → ตำบล แล้วดูขอบเขตตำบลพร้อมตำแหน่งและชื่อหมู่บ้านครบทุกหมู่ ดาวน์โหลดเป็นภาพ PNG ได้ฟรี

✨
สร้าง prompt แผนที่แหล่งเรียนรู้

กรอกข้อมูลแหล่งเรียนรู้ในตำบล ระบบจะสร้างคำสั่ง (prompt) ให้คัดลอกไปใช้กับ AI สร้างภาพตัวอื่นได้ทันที

🧊
แผนที่โต้ตอบได้ + มุมมอง 3 มิติ

ชี้ที่หมุดเพื่อดูชื่อและพิกัด คลิกเพื่อไฮไลต์พื้นที่ของหมู่บ้านนั้น ซูม เลื่อน และหมุนดูแบบ 3 มิติได้

โปรดทราบก่อนใช้งาน
  • ข้อมูลนี้จัดทำเพื่อการศึกษา ไม่ใช่เอกสารราชการ และไม่ควรใช้อ้างอิงทางกฎหมายหรือการรังวัดที่ดิน
  • เส้นแบ่งพื้นที่รายหมู่บ้านเป็นการคำนวณโดยประมาณ (Voronoi) จากพิกัดหมู่บ้าน ไม่ใช่ขอบเขตปกครองจริง
  • ข้อมูลกรุงเทพมหานครไม่มีรายชื่อหมู่บ้าน เพราะใช้ระบบเขต/แขวง ไม่ใช่ตำบล/หมู่บ้าน

✨ สร้าง Prompt แผนที่แหล่งเรียนรู้

กรอกข้อมูลด้านล่าง ระบบจะสร้างคำสั่งภาษาไทยให้อัตโนมัติ คัดลอกไปวางใน AI สร้างภาพตัวใดก็ได้ (เช่น Claude, ChatGPT, Gemini, Midjourney)

เลือกตำบลก่อน แล้วช่องข้อมูลจะถูกเติมให้อัตโนมัติ

💡 prompt นี้ใช้สำหรับสร้างภาพประกอบ ผลลัพธ์จาก AI เป็นภาพเชิงสื่อสาร ไม่ใช่แผนที่เชิงพิกัดที่ถูกต้องตามภูมิศาสตร์

ขอบเขตตำบล — thailand_gis (HDX COD-AB Thailand) · รายชื่อและพิกัดหมู่บ้าน — กรมการปกครอง กระทรวงมหาดไทย · จัดทำเพื่อการศึกษา ไม่ใช่เอกสารราชการ
