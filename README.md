# แผนที่ตำบล + รายชื่อหมู่บ้าน

เว็บไซต์ static (ไม่มีค่าใช้จ่าย ไม่ต้องมี backend) สำหรับเลือกจังหวัด → อำเภอ → ตำบล
แล้วดาวน์โหลดภาพแผนที่ขอบเขตตำบลพร้อมรายชื่อหมู่บ้านทั้งหมดเป็น PNG

จัดทำเพื่อการศึกษา ไม่ใช่เพื่อการค้า โดยใช้ข้อมูลจาก 2 แหล่ง:

- **ขอบเขตตำบล (polygon)**: [prasertcbs/thailand_gis](https://github.com/prasertcbs/thailand_gis)
  (แปลงมาจาก HDX COD-AB Thailand)
- **รายชื่อ + พิกัดหมู่บ้าน**: [ข้อมูลที่ตั้งและสภาพทั่วไปของหมู่บ้านใน 76 จังหวัด](https://catalog.dopa.go.th/dataset/gis-01)
  โดยกรมการปกครอง กระทรวงมหาดไทย (Open Data Common license, ปรับปรุงล่าสุด มิ.ย. 2568)

## โครงสร้างโปรเจกต์

- `data/raw/tambon_shp/` — shapefile ขอบเขตตำบลรายจังหวัด 77 ไฟล์ (จาก thailand_gis)
- `data/raw/dopa_village/` — ไฟล์ JSON รายชื่อ/พิกัดหมู่บ้านรายจังหวัด 76 ไฟล์ (จากกรมการปกครอง)
- `scripts/download_provinces.py` — ดาวน์โหลด shapefile ขอบเขตตำบล
- `scripts/download_dopa.py` — ดาวน์โหลดข้อมูลหมู่บ้านจากกรมการปกครอง
- `scripts/build.py` — จับคู่ขอบเขตตำบลกับรายชื่อหมู่บ้าน (จับคู่ด้วยชื่อจังหวัด/อำเภอ/ตำบล
  พร้อม fallback แบบ prefix/near-miss/พิกัดใกล้เคียง สำหรับกรณีชื่อในไฟล์ขอบเขตถูกตัดทอน) แล้ว export เป็น JSON
- `data/processed/index.json` — ดัชนีจังหวัด → อำเภอ → ตำบล (ใช้สร้าง dropdown)
- `data/processed/tambon/<PCODE>.json` — ขอบเขต (polygon) + รายชื่อหมู่บ้านพร้อมพิกัด ต่อ 1 ตำบล
- `docs/` — เว็บไซต์ static (index.html, style.css, app.js) พร้อมสำเนาข้อมูลใน `docs/data/`
  (ชื่อโฟลเดอร์ `docs` ตามข้อกำหนดของ GitHub Pages สำหรับ deploy จาก branch `main`)

## รันดูตัวอย่างบนเครื่อง

```bash
cd docs
python3 -m http.server 8743
```

แล้วเปิด http://localhost:8743

## Deploy ฟรี

เว็บนี้ deploy อยู่ที่ **GitHub Pages** จากโฟลเดอร์ `docs/` ของ branch `main` โดยตรง
(ไม่ต้องตั้งค่า build ใด ๆ) — จะอัปเดตเว็บทุกครั้งที่ push โค้ดใหม่เข้า `main`

หมายเหตุ: `docs/data/` มีขนาดประมาณ 360MB (ไฟล์ JSON ต่อตำบล ~7,400 ไฟล์)
โฟลเดอร์นี้จำเป็นต้องอยู่คู่กับเว็บเสมอ

## การสร้างข้อมูลใหม่ (ถ้าต้นทางอัปเดต)

```bash
python3 scripts/download_provinces.py   # ดาวน์โหลด shapefile ตำบลรายจังหวัดใหม่
python3 scripts/download_dopa.py        # ดาวน์โหลดข้อมูลหมู่บ้านจากกรมการปกครองใหม่
python3 scripts/build.py                # จับคู่ข้อมูลใหม่ + export JSON
rm -rf docs/data/processed && cp -r data/processed docs/data/processed  # sync เข้าเว็บ
```

## ข้อจำกัดที่ทราบอยู่แล้ว

1. **กรุงเทพมหานคร**: ข้อมูลจากกรมการปกครอง (gis-01) ครอบคลุมเฉพาะ 76 จังหวัด
   (กรุงเทพฯ ปกครองด้วยระบบเขต/แขวงภายใต้ กทม. ไม่ใช่ระบบอำเภอ/ตำบล/หมู่บ้านแบบจังหวัดอื่น)
   จึงไม่มีรายชื่อหมู่บ้านให้แสดงสำหรับแขวงในกรุงเทพฯ (มีแค่ขอบเขตแผนที่)
2. **ตำบลที่ขาดข้อมูล**: หลัง join กับข้อมูลกรมการปกครองแล้ว เหลือตำบลนอกกรุงเทพฯ
   เพียง 1 แห่ง (ตำบลท่าแฝก อ.ท่าปลา จ.อุตรดิตถ์) ที่ไม่มีข้อมูลหมู่บ้านในชุดข้อมูลต้นทาง
   ครอบคลุมหมู่บ้านได้ 80,388 จาก 80,397 รายการ (99.99%)
3. **ชื่ออำเภอ/ตำบลในไฟล์ขอบเขต**: shapefile ขอบเขตตำบล (thailand_gis) มีบางจังหวัดที่ชื่อ
   อำเภอ/ตำบลถูกตัดทอนหรือสะกดคลาดเคลื่อนเล็กน้อย สคริปต์ build.py แก้ไขโดยจับคู่แบบ
   prefix/near-miss กับชื่อที่ถูกต้องจากกรมการปกครอง และใช้ชื่อที่ถูกต้องแสดงผลแทน
4. **ลิขสิทธิ์ข้อมูลขอบเขต**: repo thailand_gis ไม่มีไฟล์ license ระบุไว้ชัดเจน
   ข้อมูลเดิมมาจาก HDX (data.humdata.org/dataset/cod-ab-tha) ควรใส่เครดิตแหล่งที่มาเสมอ
   ส่วนข้อมูลหมู่บ้านจากกรมการปกครองเป็น Open Data Common (เปิดให้ใช้ได้ทั้งไม่เชิงพาณิชย์และเชิงพาณิชย์
   โดยควรอ้างอิงแหล่งที่มา)
