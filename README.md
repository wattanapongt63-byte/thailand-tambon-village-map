# แผนที่ตำบล + รายชื่อหมู่บ้าน

เว็บไซต์ static (ไม่มีค่าใช้จ่าย ไม่ต้องมี backend) สำหรับเลือกจังหวัด → อำเภอ → ตำบล
แล้วดาวน์โหลดภาพแผนที่ขอบเขตตำบลพร้อมรายชื่อหมู่บ้านทั้งหมดเป็น PNG

จัดทำเพื่อการศึกษา ไม่ใช่เพื่อการค้า โดยใช้ข้อมูลจาก
[prasertcbs/thailand_gis](https://github.com/prasertcbs/thailand_gis)
(แปลงมาจาก HDX COD-AB Thailand และ TH_VILLAGE2012)

## โครงสร้างโปรเจกต์

- `data/raw/` — shapefile ต้นฉบับที่ดาวน์โหลดมา (ขอบเขตตำบลรายจังหวัด 77 ไฟล์ + จุดหมู่บ้านทั่วประเทศ)
- `scripts/build.py` — สคริปต์จับคู่ขอบเขตตำบลกับรายชื่อหมู่บ้าน (จับคู่ด้วยชื่อจังหวัด/อำเภอ/ตำบล) แล้ว export เป็น JSON
- `data/processed/index.json` — ดัชนีจังหวัด → อำเภอ → ตำบล (ใช้สร้าง dropdown)
- `data/processed/tambon/<PCODE>.json` — ขอบเขต (polygon) + รายชื่อหมู่บ้านพร้อมพิกัด ต่อ 1 ตำบล
- `docs/` — เว็บไซต์ static (index.html, style.css, app.js) พร้อมสำเนาข้อมูลใน `docs/data/`
  (ชื่อโฟลเดอร์ `docs` ตามข้อกำหนดของ GitHub Pages สำหรับ deploy จาก branch `main`)

## รันดูตัวอย่างบนเครื่อง

```bash
cd docs
python3 -m http.server 8743
```

แล้วเปิด http://localhost:8743

## Deploy ฟรี

เว็บนี้ deploy อยู่ที่ **GitHub Pages** จากโฟลเดอร์ `docs/` ของ branch `main` โดยตรง
(ไม่ต้องตั้งค่า build ใด ๆ) — จะอัปเดตเว็บทุกครั้งที่ push โค้ดใหม่เข้า `main`

หมายเหตุ: `docs/data/` มีขนาดประมาณ 360MB (ไฟล์ JSON ต่อตำบล ~7,400 ไฟล์)
โฟลเดอร์นี้จำเป็นต้องอยู่คู่กับเว็บเสมอ

## การสร้างข้อมูลใหม่ (ถ้าต้นทางอัปเดต)

```bash
python3 scripts/download_provinces.py   # ดาวน์โหลด shapefile ตำบลรายจังหวัดใหม่
python3 scripts/build.py                # จับคู่ข้อมูลใหม่ + export JSON
cp -r data/processed docs/data/processed # sync เข้าเว็บ
```

## ข้อจำกัดที่ทราบอยู่แล้ว

1. **กรุงเทพมหานคร**: ชุดข้อมูล TH_VILLAGE2012 ไม่ได้แยกหมู่บ้าน/ชุมชนตามแขวง
   จึงไม่มีรายชื่อหมู่บ้านให้แสดงสำหรับทุกแขวงในกรุงเทพฯ (มีแค่ขอบเขตแผนที่)
2. **ตำบลที่ขาดข้อมูล**: มีตำบลประมาณ 1,500 แห่ง (นอกกรุงเทพฯ) ที่ไม่มีอยู่ใน
   ชุดข้อมูลหมู่บ้านปี 2012 เลย (อาจเกิดจากการแบ่ง/เปลี่ยนแปลงเขตปกครองหลังปี 2012
   หรือข้อมูลต้นทางไม่ครบ) — จะแสดงเฉพาะขอบเขตแผนที่โดยไม่มีรายชื่อหมู่บ้าน
3. **ลิขสิทธิ์ข้อมูล**: repo ต้นทางไม่มีไฟล์ license ระบุไว้ชัดเจน ข้อมูลเดิมมาจาก
   HDX (data.humdata.org/dataset/cod-ab-tha) ควรใส่เครดิตแหล่งที่มาเสมอเมื่อเผยแพร่
   และหลีกเลี่ยงการใช้เชิงพาณิชย์โดยไม่ได้ตรวจสอบสิทธิ์เพิ่มเติม
